Cara kerja Admin → User

  1. Ubah apa saja di bagian kiri. Preview di kanan langsung berubah (draft).
  2. Simpan & terapkan — perubahan aktif di browser ini untuk semua sesi User.
  3. Rilis — di Cadangan & Rilis, unduh site-config.js lalu timpa js/data/site-config.js agar komputer lain ikut berubah.
  4. Setiap simpan membuat versi cadangan yang bisa dipulihkan (15 versi terakhir).

      Pengaturan CSV

      Pisahkan dengan koma. Mode Advance mengenali awalan dari angka terakhir Source UID (mis. akhir 2 → awalan berakhiran 2).
      Dipakai bila User belum pernah memilih mode.
      Format hh:mm:ss:ff@25.
      Mode yang tersedia untuk User

      Struktur CSV tetap 43 kolom (3 UID + 10 klip × 4), CRLF, UTF-8 tanpa BOM. Untuk mengganti teks/label di CSV Maker gunakan Nama Elemen dengan halaman CSV Maker.

      Fitur Scene Deck

      • ✓TCR satu baris — "TCR IN : hh:mm:ss:ff TCR OUT : hh:mm:ss:ff" dengan spasi tak-putus agar pasangan tidak terpotong.
      • ✓Embed Type baru — 10 jenis signage/placement + KEY LOGO khusus; jenis lama (Poster Board, Stand Signage, Object Placement) tetap terbaca.
      • ✓Pratinjau seluruh slide — cover, ringkasan, semua scene, penutup; tombol ‹ ›, panah keyboard, Home/End, daftar slide.
      • ✓Logo slide penutup diambil dari template untuk pratinjau.
